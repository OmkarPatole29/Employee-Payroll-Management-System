# Employee Payroll System

A console-based Employee Payroll System developed in Java to practice
Object-Oriented Programming concepts.

## Features

- Add employees
- Remove employees
- Display employee details
- Calculate salary for full-time employees
- Calculate salary for part-time employees

## OOP Concepts Practiced

- Abstraction
- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding
- Constructors
- Java Collections

## Learning Note

This project was developed while following a Java OOP tutorial and was used
as a hands-on learning project.

While building the project, I implemented and modified most of the code
independently based on my understanding of Java and Object-Oriented
Programming concepts. The project helped me strengthen my understanding of
abstraction, inheritance, encapsulation, polymorphism, method overriding,
constructors, and Java Collections.

I also used this project to practice a complete Git and GitHub workflow,
